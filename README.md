# 🍴 Vivaha Bhojanambu – Restaurant Website

A responsive and modern **restaurant website** built using **HTML5 and CSS3**.
The website is designed to provide customers with an attractive online experience to explore the restaurant, view popular dishes, check offers, browse the gallery, and reserve a table.

## 🌐 Project Overview

**Vivaha Bhojanambu** is a frontend restaurant website featuring a clean and responsive design with sections for:

* 🏠 Home
* 👨‍🍳 About Us
* 🍽️ Menu
* 🎁 Special Offers
* 🖼️ Gallery
* 📞 Contact & Table Reservation
* 🔻 Footer

The project focuses on creating a simple, user-friendly restaurant interface using only **HTML and CSS**.

## 🚀 How to Run the Project

